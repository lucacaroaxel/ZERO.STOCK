# ZERO.STOCK 

ZERO.STOCK è un Proof of Concept (PoC) decentralizzato sviluppato per la tracciabilità della moda sostenibile e l'economia circolare. Il progetto integra Smart Contract su rete Ethereum Sepolia e storage IPFS per creare "Gemelli Digitali" dei capi d'abbigliamento. 

L'obiettivo dell'applicativo è combattere il greenwashing e il fast fashion automatizzando il Digital Product Passport (DPP) per produzioni artigianali Zero Waste, offrendo al contempo un'esperienza utente fluida ispirata ai principi della Calm Technology.

## Stack Tecnologico

* **Frontend:** React.js (Single Page Application), TypeScript, Tailwind CSS, Framer Motion
* **Web3 Middleware:** Ethers.js (v6)
* **Decentralized Storage:** IPFS tramite gateway Pinata
* **Smart Contract:** Solidity (v0.8.19)
* **Rete Blockchain:** Ethereum Testnet (Sepolia)
* **Wallet / Provider:** MetaMask
